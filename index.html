Features

为真实课堂设计

不是通用工具，而是照着老师上课的动线做的：点名、加分、记小组、下课走人。

随机点名

滚动动画抽人，支持不重复模式与历史记录，一轮抽完自动重置，抽过谁一目了然。

课堂计分

个人计分与整组积分一键切换，加分可选科目，输入组长学号即可给全组加分。

积分商城

积分可消费：自定义商品与价格、兑换扣分、兑换记录留档，让积分真的"有用"。

自定义计时器

课堂倒计时、正计时随手开，结束自动响铃，铃声用 WebAudio 合成，不依赖音频文件。

多班数据隔离

初三9班 / 初三10班独立存储、独立统计、独立导出，登录即选班，互不串数据。

云端备份

一键把整班数据存到私有 GitHub Gist，换机或重装后原样恢复，数据永远在你自己手里。

详细数据与筛选

按学生、科目、时间筛选明细，个人趋势与小组排名一屏看完，导出即用。

安全与隐私

数据只存在本机；清空、分班等危险操作需插入 U 盘密钥验证，误触也不会丢数据。

Appearance

四种界面风格

About

关于 FileOS

FileOS 起源于西光中学的一间教室：需要一个能在投影上点名的窗口，一个能记住每组积分的表格， 一个不会把两个班数据搞混的记账本。于是有了它，并一直在课堂里被使用和修改。
